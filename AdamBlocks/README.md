# Adam Blocks

Client-side Fabric mod for Minecraft 1.21.11. Highlights blocks you choose
through walls, with a hover tooltip that names the block or lists grouped counts.

## Use
- Open the menu with Right Shift, or from Mod Menu (Adam Blocks > config button).
- Press "+ Add block", search, and click any block to track it.
- Per block: On/Off, Edit (red/green/blue sliders and fill opacity), x to remove.
- Settings: range, group distance (how close blocks must be to merge), menu key.
- Aim the crosshair at a highlight to see the tooltip.

## Build
Push to GitHub, open the Actions tab, run "build", and download the jar from
the artifact. If a dependency version fails to resolve, copy the version lines
from your working Adam-freecam gradle.properties.

Config file: config/adamblocks.json
